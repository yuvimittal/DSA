
# Programming Paradigms (Other than OOP)

## What is a Programming Paradigm?

> A **programming paradigm** is a style or approach to writing programs — it defines **how a program is structured and how its execution is modeled**.

Programming languages are often classified based on the **paradigm(s)** they support.

---

## Broad Classification of Programming Paradigms

Programming paradigms are commonly divided into **two major categories**:

1️⃣ **Imperative Programming Paradigm**
2️⃣ **Declarative Programming Paradigm**

---

## 1️⃣ Imperative Programming Paradigm

### Definition

> Imperative programming focuses on **HOW** a program operates.
> It describes the program as a sequence of **commands that change the program’s state**.

You explicitly tell the computer:

* What to do
* How to do it
* In what order to do it

---

### Characteristics

* Uses variables
* Uses loops and conditionals
* Explicit control flow
* State changes over time

---

### Sub-types of Imperative Paradigm

### a) Procedural Programming Paradigm

**Definition:**
Procedural programming organizes code into **procedures / functions**, which are executed step-by-step.

**Key points:**

* Top-down approach
* Functions operate on shared data
* Emphasis on sequence of steps

**Examples:**

* C
* Pascal
* Fortran

---

### b) Object-Oriented Programming (OOP)

**Definition:**
OOP organizes programs around **objects**, which encapsulate **data (attributes)** and **behavior (methods)**.

**Key concepts:**

* Encapsulation
* Abstraction
* Inheritance
* Polymorphism

**Examples:**

* C++
* Java
* Python

📌 OOP is considered **imperative** because objects change state over time.

---

### c) Parallel Programming Paradigm

**Definition:**
Parallel programming divides a problem into **independent sub-tasks** that execute **simultaneously**.

**Key points:**

* Improves performance
* Uses multiple cores / processors
* Focus on synchronization and concurrency

**Examples:**

* CUDA
* OpenMP
* MPI

---

## 2️⃣ Declarative Programming Paradigm

### Definition

> Declarative programming focuses on **WHAT** the program should accomplish, not **HOW** it should do it.

You describe the desired result, and the language/runtime figures out the execution.

---

### Characteristics

* Minimal explicit control flow
* No or limited state changes
* More readable and concise
* Easier reasoning and debugging

---

### Sub-types of Declarative Paradigm

---

### a) Logical Programming Paradigm

**Definition:**
Logic programming is based on **formal logic**, where programs consist of **facts, rules, and queries**.

**Key points:**

* Uses predicates and relations
* Execution is driven by inference
* Focus on problem constraints

**Example:**

* Prolog

---

### b) Functional Programming Paradigm

**Definition:**
Functional programming constructs programs by **composing pure functions**.

**Key concepts:**

* Immutability
* No side effects
* Higher-order functions
* Recursion instead of loops

**Examples:**

* Haskell
* Lisp
* Scala
* Functional features in C++ / Python

---

### c) Database Programming Paradigm

**Definition:**
Database programming focuses on **data querying and manipulation** rather than algorithmic steps.

**Key points:**

* Data-centric
* Uses declarative query languages
* Optimized by query planners

**Examples:**

* SQL
* PL/SQL

---

## Summary Table

| Paradigm    | Focus | Key Idea               |
| ----------- | ----- | ---------------------- |
| Imperative  | HOW   | Step-by-step execution |
| Procedural  | HOW   | Procedures & functions |
| OOP         | HOW   | Objects & behavior     |
| Parallel    | HOW   | Simultaneous execution |
| Declarative | WHAT  | Desired outcome        |
| Logical     | WHAT  | Rules & facts          |
| Functional  | WHAT  | Function composition   |
| Database    | WHAT  | Data querying          |

---

## Interview-ready conclusion 📝

> Apart from OOP, programming paradigms include imperative paradigms such as procedural and parallel programming, and declarative paradigms such as functional, logical, and database programming, each focusing on different ways of expressing computation.

---

## One-line takeaway 🔥

> **Imperative paradigms describe how a task is performed, while declarative paradigms describe what result is required.**
